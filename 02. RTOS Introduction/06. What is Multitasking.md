# What is Multitasking?
- Let's see the analogy for the multi-tasking. Suppose a person has a lots of tasks in a day to be completed e.g. Having Breakfast, Sending Emails, Meetings, Writing Notes, etc.

<img src="images/-6.png" width=600px>

- Now suppose we have several assistants to increase the productivity, e.g.
  - **Assistant 1** for Sending Emails.
  - **Assistant 2** for Receiving Calls on our behalf.
  - **Assistant 3** for Managing Appointments.

<img src="images/-7.png" width=600px>

- Similarly a multi tasking application an application may consist of multiple tasks. Each task is performs a function.

- For Example:
  - Temperature Monitoring Application
    - **Task 1** : Sensor Data Gathering
    - **Task 2** : Updating display
    - **Task 3** : User input processing

<img src="images/-8.png" width=600px>

## What is a Task?
- A Task is a piece of code which can be schedulable on the CPU to execute.

## How to schedule multiple tasks on a processor which has got only one core?
1. Give a time slice for each task to run for that time.
2. Running multiple tasks on a processor is accomplished by the "Scheduler".

<img src="images/-9.png" width=600px>

## What is a Scheduler?
- Scheduler is the one who takes care of scheduling all this tasks onto the CPU to execute.
- In a multi-tasking environment the Scheduler plays an important role, it decides who will be taking the CPU next.

<img src="images/-10.png" width=600px>

## How multiple tasks run on a multi core processor?
- The multi-core processor does not require a Scheduler to run the applications.
- Multiple tasks can run on multiple cores.
- But in the Embedded Systems world we do not use a multi-core processor to run different tasks.
- We have a single core with multi task scenario.
