# FreeRTOSConfig.h and other settings

## 1. Purpose of FreeRTOSConfig.h
- `FreeRTOSConfig.h` is an application-specific C header file used to customize the FreeRTOS kernel.
- It is not included in the FreeRTOS kernel download.
- Every FreeRTOS application must make this file available through the preprocessor include path.
- The file contains configuration items written as C macros.

### Configuration Examples
- `configUSE_PREEMPTION` controls the scheduler mode:
	- `1` enables preemption.
	- `0` disables preemption and allows cooperative scheduling.
- `configTICK_RATE_HZ` sets the FreeRTOS tick frequency. Default `FreeRTOSConfig.h` uses `1000` Hz.
- FreeRTOS provides documentation for the meaning and significance of each configuration item.
- Some configuration items are `processor-specific`, so a configuration file for one processor architecture may not be suitable for another.

## 2. Add a Compatible Configuration File(If available, not available in our case)
0. In the version `v202604.01` the `Demo` folder is not available.
1. Open the extracted FreeRTOS kernel download and enter its `Demo` folder.
2. Search for a demo application for the same microcontroller used by the project.
3. Copy that demo application's `FreeRTOSConfig.h` into the project's `ThirdParty/FreeRTOS` folder.
4. Use the demo file as a starting point, but review and customize it for the application instead of trusting it blindly.
5. Refresh the project in `STM32CubeIDE` so the file appears.
6. Add the `ThirdParty/FreeRTOS` folder to the compiler include paths.

## 3. Resolve the Compiler Definition
- Build the project after adding `FreeRTOSConfig.h`.

## 4. Resolve Exception Handler Conflicts
- FreeRTOS's Cortex-M port provides implementations for handlers such as:
	- `SVC_Handler` - System Service Call via SWI instruction.
	- `PendSV_Handler` - Pendable request for system service.
	- `SysTick_Handler` - System Tick Timer.
- The STM32Cube-generated `it.c` file may also contain definitions for these handlers, causing multiple-definition errors.
- The FreeRTOS port uses these handlers to support the scheduler, context switching, and RTOS tick processing.

### Disable Duplicate Generated Handlers
1. Open the project's `.ioc` file in the STM32Cube device configuration tool.
2. Open **System Core > NVIC**.
3. Open the **Code Generation** tab.
4. Disable the generated entries for:
	 - Pendable request for system service (`PendSV`).
	 - Time base: System tick timer (`SysTick`).
	 - System service call via SWI Instruction (`SVC_Handler`).
5. Save or generate the project code so the duplicate handler definitions are removed from `it.c`.
6. Build the project again.

## 5. Disable Unused Hooks
- If the build reports undefined references to FreeRTOS hook functions, disable the corresponding hooks in `FreeRTOSConfig.h`:
	- Set `configUSE_TICK_HOOK` to `0`.
	- Set `configUSE_MALLOC_FAILED_HOOK` to `0`.
	- Set `configCHECK_FOR_STACK_OVERFLOW` to `0`.
- These are FreeRTOS hook functions and will be covered later in the course.

## 6. Build Result
- Build the project again after applying the configuration and handler changes.
- The project should build successfully, confirming that the FreeRTOS kernel has been integrated without build errors.

## 7. Another way of getting the `FreeRTOSConfig.h` file
- Generate a FreeRTOS project from the `STM32CubeMX`.
- It will automatically generate the `FreeRTOSConfig.h` file in the Inc folder of the Project.
- Get the file from there.
