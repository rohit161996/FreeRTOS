# 01. Creating new STM32 project

## 1. Objective
- Create and compile a basic FreeRTOS-based project for the microcontroller.
- The project will be used repeatedly to create tasks, including tasks that can print `Hello World`.

## 2. Create the Workspace
- Create a new folder named `FreeRTOS workspace` to store the FreeRTOS projects.
- Open `STM32CubeIDE`.
- When prompted for a workspace, select the `FreeRTOS workspace` folder and launch the IDE.

## 3. Create the STM32 Project
1. Select **File > STM32 Project Create/Import > STM32CubeIDE Empty Project > Next > Board Selector >  > Next**.
2. In the board selector, search for and select the `STM32F407G-DISC1` board (`STM32F407G-DISC1` Disco board).
3. Set the project name to `00. FreeRTOS Project`.
4. Keep the target language as `C`.
5. Keep the targeted binary type as `Executable`.
6. Click **Finish**.
