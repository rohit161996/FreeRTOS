# 03. Include path settings

## 1. Add FreeRTOS Include Paths
- The previous build failed because the compiler could not find header files provided by the FreeRTOS kernel.
- In `STM32CubeIDE`, right-click the project and select **Properties**.
- Expand the project settings and select **Settings**.
- Open **Tool Settings** and select **MCU GCC Compiler**.
- Select **Include paths** and use **Add** to add the required workspace paths.


### 2. FreeRTOS Kernel Headers
```bash
../ThirdParty/FreeRTOS/include
```

### 3. Architecture Headers
```bash
../ThirdParty/FreeRTOS/portable/GCC/ARM_CM4F
```

## 4. Build Result
- Build the project again.
- Most FreeRTOS header-file errors should now be resolved.
- The next error is that `FreeRTOSConfig.h` cannot be found.

## 5. FreeRTOSConfig.h
- `FreeRTOSConfig.h` is a configuration header used to customize the FreeRTOS kernel.
- It is not included in the FreeRTOS kernel source package.
- The project must create and add this file separately.
